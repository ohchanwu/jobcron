Gemini에는 시작하기 좋은 무료 API 등급이 있습니다. gemini-3.5-flash-lite 기준 약 하루 500회의 API 요청을 사용할 수 있어요. 같은 Google 프로젝트를 Jobcron에서만 사용한다면 사용 한도에 걸릴 가능성은 낮아요. 같은 프로젝트의 API 키를 다른 용도로 함께 쓰면 한도에 도달할 수 있어요. 드물게 한도에 도달하면 다음 할당량 초기화까지 기다리거나 유료 등급이 연결된 프로젝트의 키를 사용하세요.

무료 등급에서는 Google이 프롬프트와 응답을 제품 개선에 사용할 수 있어요. AI 프로필 입력란에 민감, 기밀, 개인 식별 정보를 넣을 때 주의하세요.

설정 순서

  1. Google AI Studio에 로그인 ↗새 탭에서 열림하세요.
  2. API 키 만들기를 선택하세요.

    프로젝트가 없을 때만 프로젝트를 만들거나 선택하라는 안내가 표시돼요.

  3. 표시된 API 키를 복사하세요.

    채팅, 메모, 화면 캡처에 남기지 마세요.

  4. Jobcron 프로필 설정에서 Google Gemini를 선택하고 API 키 입력란에 붙여넣으세요.
  5. 모델에서 gemini-3.5-flash-lite (Flash-Lite)를 선택한 뒤 저장하세요.
  6. 브리핑에서 첫 실제 AI 평가를 실행하세요.

첫 실제 AI 평가 결과

성공하면 공고에 근거가 포함된 AI 분석이 표시돼요. 실패해도 일반 점수는 계속 사용할 수 있고, 아래 메시지에 따라 설정을 바로잡은 뒤 실제 평가를 다시 실행하면 됩니다.

잘못된 키 또는 권한 없음
“AI 키를 확인해주세요”가 표시돼요. 키를 다시 복사하거나 새 키로 교체하세요.
할당량 소진 또는 HTTP 429
Google AI Studio 사용량·할당량 화면 ↗새 탭에서 열림을 확인하고 한도가 회복될 때까지 기다리세요.
모델 불일치
프로필의 제공자가 Gemini이고 모델이 Flash-Lite인지 확인하세요.
지역 제한
Google 계정 또는 프로젝트에서 Gemini API를 사용할 수 있는 지역인지 Google 안내를 확인하세요.
