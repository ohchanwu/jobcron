동영상 없이도 이 안내만 따라 첫 평가까지 완료할 수 있어요. Google 화면의 이름이나 위치는 바뀔 수 있지만 필요한 단계는 같아요.

시작하기 전에

Gemini에는 시작하기 좋은 무과금 API 등급(unpaid API tier)이 있지만 영구 제공이나 고정 요청 수를 보장하지 않아요. Google이 지역별 제공 여부와 사용 한도를 정합니다.

무과금 등급에서는 Google이 프롬프트와 응답을 제품 개선에 사용할 수 있어요. AI 프로필 입력란에는 이력서나 민감한 정보, 기밀 정보, 개인 식별 정보를 넣지 마세요.

설정 순서

  1. Google AI Studio에 로그인 ↗새 탭에서 열림하세요.
  2. 안내에 따라 프로젝트를 만들거나 선택하세요.
  3. API 키 만들기를 선택하세요.
  4. 표시된 API 키를 복사하세요. 채팅, 메모, 화면 캡처에 남기지 마세요.
  5. Jobcron 프로필 설정에서 Google Gemini를 선택하고 API 키 입력란에 붙여넣으세요.
  6. 모델에서 gemini-3.5-flash-lite (Flash-Lite)를 선택한 뒤 저장하세요.
  7. 브리핑에서 첫 실제 AI 평가를 실행하세요. 이 요청이 저장한 키, 선택 모델, Google 엔드포인트, Jobcron의 정상 요청 경로를 함께 확인하는 유일한 연결 확인이에요. 별도의 연결 테스트 버튼이나 요청은 없어요.

첫 실제 AI 평가 결과

성공하면 공고에 근거가 포함된 AI 분석이 표시돼요. 실패해도 일반 점수는 계속 사용할 수 있고, 아래 메시지에 따라 설정을 바로잡은 뒤 실제 평가를 다시 실행하면 됩니다.

잘못된 키 또는 권한 없음
“AI 키를 확인해주세요”가 표시돼요. 키를 다시 복사하거나 새 키로 교체하세요.
할당량 소진 또는 HTTP 429
Google AI Studio 사용량·할당량 화면 ↗새 탭에서 열림을 확인하고 한도가 회복될 때까지 기다리세요.
모델 불일치
프로필의 제공자가 Gemini이고 모델이 Flash-Lite인지 확인하세요.
지역 제한
Google 계정 또는 프로젝트에서 Gemini API를 사용할 수 있는 지역인지 Google 안내를 확인하세요.

키 보관·교체·폐기

키는 Jobcron 서버에서 Google Gemini로 직접 요청할 때만 사용하고 데이터베이스에 저장하기 전에 암호화해요. 저장된 키 원문은 브라우저에 다시 표시하지 않아요.

키를 교체하려면 프로필에 새 키를 저장하세요. 사용을 끝내려면 Jobcron에서 저장된 키를 삭제하고 Google AI Studio에서도 키를 폐기하세요. Jobcron은 Google의 데이터 보관 정책을 통제하지 않아요.
